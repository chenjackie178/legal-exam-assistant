## ✨ 项目简介

法考助手是一个面向法律职业资格考试（法考）考生的智能学习辅助工具。基于 2022-2024 年三年法考客观题真题全量数据和完整知识点体系，提供**知识点查询、真题检索、考点分析和智能问答**四大核心能力。

> 🎯 **一句话总结**：装上就能用，不需要任何外部 API Key，纯本地数据查询 + LLM 智能问答。

## 🚀 核心能力

### 1️⃣ 知识点查询

按科目 → 章 → 节逐级下钻，查看每个知识点的：
- 📝 详细描述
- ⭐ 重要程度（1-5 星）
- 📜 关联法条

```
示例：查询刑法中"数罪并罚"的知识点
→ 定位到：刑法 > 刑罚论 > 数罪并罚
→ 返回：知识点描述 + 重要程度★★★★★ + 关联法条
```

### 2️⃣ 真题检索

支持多条件组合筛选：
- 按**科目**：只看某一科的所有真题
- 按**年份**：只看 2024 年考题
- 按**题型**：只看多选题
- 按**难度**：只看高难度题
- 按**关键词**：搜索题干内容
- 按**知识点**：查看某个考点对应的真题

### 3️⃣ 考点分析

- 📈 统计各知识点考查频率
- 🔥 找出高频考点（2024 年数罪并罚考了 6 题！）
- 💡 数据化备考建议，告别盲目复习

### 4️⃣ 智能问答

结合知识点和真题案例，回答法考相关问题：
- "数罪并罚和想象竞合犯有什么区别？"
- "善意取得和表见代理的关系是什么？"
- "给我出 5 道关于盗窃罪的模拟题"
